# Sources

`source` is provenance: who or what is responsible for this memory being true. It is optional on a write, and it is the field people most regret defaulting.

```typescript
await client.storeEvent({
  graph_id: "acme",
  event_kind: "fact",
  source: "user",
  context_id: "preference:theme",
  payload: { data: "prefers dark mode" },
});
```

## The ladder

<TrustLadder />

Higher means more trusted. When two memories disagree, the one from the higher source carries more weight in what comes back.

## Choosing one

Ask what would have to be wrong for this to be false:

| Source | Use it when |
| --- | --- |
| `policy` | An organization decided it. It is true because someone with authority said so |
| `verified` | It was checked, a validator passed, a human confirmed |
| `tool` | A tool produced it. A test run, a type check, a failed deploy |
| `document` | It came from a file you ingested |
| `user` | A person said it. Valuable, and still subjective |
| `assistant` | A model inferred it. Plausible, unproven |
| `derived` | Synthesised from other memories, second-hand |
| `system` | Generated by your own plumbing |

## Aliases

Four older names are still accepted and map to the preferred ones:

| Alias | Means |
| --- | --- |
| `validator` | `verified` |
| `executor` | `tool` |
| `agent` | `assistant` |
| `model` | `assistant` |

Write the preferred name in new code. The aliases exist so old code keeps working.

## Why honesty costs you later

<Callout tone="trap" title="An over-stamped guess outranks the correction">
  Stamp a model's inference as `verified` and it sits above what the user later tells you directly.
  The correction is in the graph, ranked beneath the thing it was meant to correct, and nothing in
  the system can tell you that happened.
</Callout>

The inverse is cheap: understamp and the memory is still there, just weighted more modestly. If you are unsure between two rungs, take the lower one.

## The default

Omit `source` and the server assigns one from the event kind. That is reasonable for a quick write and wrong often enough that any memory you expect to matter should say where it came from explicitly.
