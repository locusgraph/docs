# Overview

LocusGraph is the graph the products are built on. Spendgraph, BrainStorm and Locus Skill each sit
on top of it and document themselves in their own section of this host.

## How this host is laid out

Every section of the docs follows the same three-level shape:

| Level | URL | What it holds |
| --- | --- | --- |
| Host | `doc.locusgraph.com` | The index, listing every section |
| Section | `/locusgraph` | One product's docs root |
| Page | `/locusgraph/overview` | A single chapter |

Marketing pages are not here. They live on `www.locusgraph.com`, and each product signs its users in
on its own subdomain. A page on this host is documentation or it does not belong on this host.

## What is written down so far

This section is being filled in. Pages appear in the sidebar as they are written, and the sidebar is
the reading order — there is no hidden page that only search can reach.
