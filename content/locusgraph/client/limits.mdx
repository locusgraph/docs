# Limits

Every ceiling a caller can hit, collected here so you are not discovering them one incident at a time.

## Payload size

A single memory's payload is capped at **64 KB**.

That is measured in **bytes, not characters**. A payload of emoji or non-Latin text reaches the cap in far fewer characters than an English one — `"日本語"` is three characters and nine bytes.

Over the cap, the write is refused. It is not truncated, so nothing is silently half-stored.

<Callout tone="note" title="64 KB is a lot of memory">
  If you are near it, you are probably storing a document rather than a memory. Split it into the
  statements it makes, or send it through [ingest](/locusgraph/use-cases/documents).
</Callout>

## Batch size

| Call | Ceiling |
| --- | --- |
| `storeEventsBatch` | **1000** events per request |
| `transaction` | The same, and all of them commit or none do |

Past 1000, split the work. The two calls differ in guarantee, not in size — see [Batch and transactions](/locusgraph/remember/batch).

## Pagination

Reads that return lists take `page` and `page_size`. `page` is **zero-indexed** — the first page is `0`.

```typescript
await client.listContextsByType("acme", "preference", { page: 0, page_size: 50 });
```

## Rate limits

Four buckets, counted per minute:

| Bucket | Limit | Calls in it |
| --- | --- | --- |
| `spend` | **20/min** | `retrieveMemories`, `deepRecall` |
| `ingest` | **10/min** | Document ingestion |
| `write` | **120/min** | `storeEvent`, `storeEventsBatch`, `transaction`, `observe` |
| `read` | **300/min** | Everything else |

Searching is the tight one, and deliberately so — a recall is not a cheap lookup. Design around it:

- **Search once per turn, not once per question.** One well-phrased query returns what several narrow ones would
- **Writes are cheap by comparison.** 120/min, and a batch of 1000 is one request against it
- **Reads that address a context by name** — `getContext`, `listContextsByType` — sit in the 300/min bucket, so walking a known structure is not constrained the way searching is

Over the limit you get `429`. That one **is** worth retrying, after a pause — see [Errors](/locusgraph/client/errors).
