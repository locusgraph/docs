# Install

```bash
npm install @locusgraph/client
```

One package. It ships the client and every request and response type. No provider SDK, no framework, no peer dependencies to reconcile, and nothing to configure at build time.

## Your first call

```typescript
import { LocusGraphClient } from "@locusgraph/client";

const client = new LocusGraphClient({
  agentSecret: process.env.LOCUSGRAPH_AGENT_SECRET,
  graphId: "my-graph",
});

await client.storeEvent({
  graph_id: "my-graph",
  event_kind: "fact",
  payload: { data: "the user prefers dark mode" },
});
```

`serverUrl` is optional and defaults to `https://api.locusgraph.com`. [Connecting](/locusgraph/client/connecting) covers pointing it elsewhere.

## What comes with it

```typescript
import {
  LocusGraphClient,
  type ContextQuery,
  type StoreEventResponse,
} from "@locusgraph/client";
```

The class and the types come from the package root. There are no deep imports to learn. See [Types](/locusgraph/client/types).

The client covers writing, reading, contexts, review and graph creation. Three surfaces are **HTTP only** and have no method on it:

| Not in the client | Where it lives |
| --- | --- |
| Document ingestion | [Documents](/locusgraph/use-cases/documents) |
| Graph settings | [Settings](/locusgraph/graphs/settings) |
| API keys, permissions, transfer | [API keys](/locusgraph/graphs/keys) |

## Where it runs

Built on `fetch`, so it runs anywhere `fetch` is global: Node 18 and later, Bun, Deno, Cloudflare Workers, and the edge runtimes built on them. No polyfill, no bundler configuration.

<Callout tone="warn" title="Server-side only">
  The client authenticates with a bearer secret. Anything holding one is a trusted environment: a
  server, a worker, a job. Putting it in a browser bundle hands every visitor your token.
</Callout>

## Pin it

```json
{ "dependencies": { "@locusgraph/client": "0.10.1" } }
```

Pre-1.0, so a minor bump may break. [Versioning](/locusgraph/client/versioning) covers what moves and what stays.
