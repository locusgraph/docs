# Getting started

Which page to open first depends on what you came to build.

## If you are here for a product

Open that product's section directly — each one starts from its own overview:

- **Spendgraph** — what every token costs
- **BrainStorm** — thinking out loud, with the thread kept
- **Locus Skill** — working practices an agent compiles and follows

## If you are here for the graph itself

Read [Concepts](/locusgraph/concepts) first. It fixes the vocabulary the product sections lean on,
and the rest of this section assumes it.
